Portafolio profesional — Gary Salazar
AI Software Engineer & Backend Developer

Sitio web estático (HTML, CSS y JavaScript vanilla) desplegado en GitHub Pages.

Estructura
- index.html ................ Página principal (una sola página)
- assets/css/portfolio.css .. Estilos del rediseño 2026 (paleta azul marino / turquesa)
- assets/js/portfolio.js .... Lógica de interacción (navegación, scrollspy, filtros, lightbox)
- assets/img/ ............... Imágenes
- assets/vendor/ ............ Librerías de terceros (AOS, GLightbox, Isotope, Typed.js, iconos)

Cómo visualizar localmente
  python -m http.server 8080
  Luego abrir: http://localhost:8080
